Ringkasan Sistem

Akun kamu terdeteksi sebagai guru. Gunakan menu di atas untuk mengelola data Learning Center SMK DIPSA.

Tambah Mata Pelajaran

Pilih satu atau beberapa kelas. Gunakan Ctrl/⌘ + klik untuk memilih beberapa kelas.

Guru hanya dapat mengelola materi dan tugas pada mata pelajaran yang ditugaskan kepadanya. Admin dapat mengatur guru dan kelas.

Daftar Mata Pelajaran

Mata pelajaran dan penugasan guru dikelola oleh Admin.

Tambah Kelas

Daftar Kelas

Data kelas dikelola oleh Admin.

Tambah Materi

Pilih satu atau beberapa kelas tujuan. Gunakan Ctrl+klik (Windows/Linux) atau Cmd+klik (Mac).

Bisa mengupload semua jenis file yang didukung penyimpanan Supabase. Jika memilih file, file akan disimpan dan bisa dibuka oleh siswa pada mata pelajaran tersebut.

Materi akan dibuat untuk setiap mata pelajaran/kelas yang dipilih.

Daftar Materi

Tambah Tugas

Pilih satu atau beberapa kelas tujuan. Gunakan Ctrl+klik (Windows/Linux) atau Cmd+klik (Mac).

Opsional. Kosongkan jika tugas tidak memiliki batas waktu.

Jika memilih file, file instruksi akan diupload ke penyimpanan Supabase dan dapat dibuka siswa. Untuk beberapa kelas, file yang sama digunakan pada semua kelas tujuan.

Daftar Tugas

Tambah Guru Baru

Akun login guru dibuat otomatis. Penugasan mata pelajaran tetap dilakukan melalui menu Mata Pelajaran.

Data Guru

Hapus guru hanya tersedia untuk Admin. Pastikan guru yang akan dihapus tidak lagi diperlukan pada penugasan mata pelajaran.

Tambah Siswa Baru

Akun login siswa akan dibuat otomatis. Password awal dapat diberikan kepada siswa untuk login pertama kali.

Import / Export Data Siswa

Gunakan template Excel untuk menambahkan banyak siswa sekaligus. Sistem akan memeriksa email, jenis kelamin, password, dan kecocokan kelas sebelum membuat akun.

Data Siswa

Data siswa tidak dapat dihapus dari dashboard. Admin hanya dapat mengubah password akun siswa.

Pengumpulan Tugas

Pilih kelas, mata pelajaran, dan tugas untuk melihat seluruh siswa di kelas tersebut beserta keterangan apakah sudah mengirimkan tugas.

Rekap Nilai

Rekap nilai berdasarkan tanggal pengumpulan tugas. Guru hanya melihat mata pelajaran yang diampu; Admin dapat melihat seluruh data.
